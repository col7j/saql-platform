# ملحق (ب): معجم المصطلحات

| المصطلح | المعنى | الجدول/المفتاح |
|---|---|---|
| **القائد العام** | أعلى شخص وهو المشرف العام؛ واحد. ينشئ الرحلات والمجموعات واللجان، ويعتمد الخطط، ويعتمد ما يتجاوز المرصود وتعديل السجلات المعتمدة؛ لا يصرف. | `person.is_general_leader` |
| **المشرف العام** | هو نفسه القائد العام. | |
| **فريق العمل / فريق الإدارة** | أعضاء الإدارة (مصطلحان لمعنى واحد). | `person.kind='staff'` |
| **الميسّر** | عضو إدارة يشرف على مجموعة، حلقة الوصل مع الإدارة. | `grp.facilitator_id` |
| **قائد المجموعة** | مشارك من المجموعة يقود تجهيز رحلاتها. | `grp.leader_id` |
| **المشارك** | شاب جامعي (18–22) عضو في مجموعة. | `kind='participant'` |
| **قائد فريق الرحلة** | قائد المجموعة المنفِّذة، أو قائد فريق العمل المعيَّن لرحلة فريق. يرفع النماذج وينشر ويستلم العهدة. | |
| **الرحلة** | داخلية (يوم داخل المدينة) أو خارجية (أكثر من يوم، سفر وسكن). | `trip` |
| **اللقاء التطويري** | اسم الرحلة الداخلية التي ينفذها فريق العمل (ليس نوعاً مستقلاً). | |
| **الرحلة المزدوجة** | وجهة واحدة لمجموعتين متتاليتين؛ لكل منهما رحلة مستقلة. | `trip.pair_*` |
| **اللقاء الافتتاحي / الختامي** | حدثان واحد لكل منهما (الختامي يتضمن الحفل)، يقبلان صرفاً. | `program_event` |
| **لقاء التركيز** | لقاء مجموعة قصير (≤ ساعة)، به يكسب المشارك نقاط التقديم. 4 مستهدفة و8 بميزانية. | `focus_meeting` |
| **لقاء العمرة** | لقاء تركيز بعلامة وميزانية مستقلة، واحد لكل مجموعة. | `is_umrah` |
| **اللقاء الفردي** | لقاء مشارك مع ميسّره لمتابعة الخطة (4 على الأقل). | `individual_meeting` |
| **الخطة الشخصية / عجلة الحياة** | 6 جوانب: روحي، صحي، أسري، مالي، اجتماعي، تعليمي ووظيفي. | `personal_plan` |
| **لقاء الخطة الشخصية** | رحلة لفريق العمل تحمل العلامة؛ عندها تُفتح الخطة. | `is_personal_plan_meeting` |
| **وثيقة الرحلة** | الخطة الكاملة (المكان، العناوين، الوصف) — أول ما يُرفع. | `trip_doc(document)` |
| **الجدول الزمني** | الخطة أ والخطة ب ببنود (ساعة، تصنيف، تفصيل). | `schedule_*` |
| **الجدول الفعلي** | ما يثبّته متابع الرحلات لكل بند. | `actual_schedule_entry` |
| **متابع الرحلات** | عضو إدارة واحد ثابت يوثّق التنفيذ؛ لا يكون ميسّراً ولا مسؤول لجنة. | `setting tracker_person_id` |
| **المتابع البديل** | يكلَّف لرحلة محددة بعد اعتماد ق.ع. | `trip.tracker_sub_*` |
| **مسؤول التحضير** | من يسجّل حضور الرحلة ولقاءاتها (قائد الفريق أو من كلّفه). | `trip.attendance_taker_id` |
| **عضو لجنة / مسؤول لجنة** | اللجان: المالية، الإعلامية، التقنية، الإدارة العامة (+ما يُضاف). | `committee_membership` |
| **مسؤول اللجنة المالية (م.م)** | المالك الوحيد للمالية. | |
| **مسؤول اللجنة التقنية (م.ت)** | يدير الحسابات وكلمات المرور ويفتح قفل التقييم. | |
| **الصفة** | دور إضافي يتجمع على الشخص؛ مشتقة من البيانات. | `capacity_rule` |
| **قواعد التعارض** | بيانات تمنع جمع صفتين. | |
| **الصلاحية المؤقتة** | تسجيل المشاركين، تحرير الموقع، تصنيفات الجدول؛ بتاريخ انتهاء. | `temp_grant` |
| **المرصود** | المبلغ المحدد في الموازنة العامة لنوع/عنصر. | `program_budget_version` |
| **طلب الميزانية** | طلب مبلغ لنشاط؛ يمر بمسار حسب المرصود. | `budget_request` |
| **الموازنة التفصيلية** | جدول تصنيف ← بند ← عدد × سعر. | `budget_request_line` |
| **العهدة** | مبلغ يحوَّل لمسؤول عن نشاط ويُغلق بالفواتير. | `custody` |
| **الدفعة المؤجلة** | الباقي من المعتمد حين لا يكفي رصيد المحفظة. | |
| **المحفظة** | رصيد مسؤول المالية الفعلي (إيداعات وصرف). | `wallet_entry` |
| **الصرف المباشر** | صرف م.م بنفسه من المحفظة بفاتورة بلا عهدة. | `direct_spend` |
| **نموذج الصرف** | فاتورة/إيصال تحويل بأسطر يرفعه صاحب العهدة. | `spend_form` |
| **الفائض / العجز** | الفرق بين المحوَّل والمقبول عند الإغلاق. | |
| **التجزئة** | فواتير صغيرة متكررة لنفس المورد والنشاط (تنبيه). | |
| **طلب تعديل سجل معتمد** | طريق تعديل المعتمد بموافقة ق.ع. | `edit_request` |
| **الرسوم** | متابعة مسدد/جزئي/غير مسدد للمشاركين. | `fee_record` |
| **التقييم 50/50** | نصف فردي ونصف جماعي. | `eval.split` |
| **النقاط كسب فقط** | لا خصم أبداً. | |
| **قفل التقييم** | تُقفل الإعدادات بعد الحفظ؛ يفتحها م.ت. | `evaluation_lock` |
| **التميّز** | نقاط ثابتة عن كل مرة تقديم بعد الأولى. | `presentingExtraBonus` |
| **الضيف** | مقدّم من خارج النظام؛ خارج التقييم والترتيب. | `guest_name` / `trip_guest` |
| **الداعم / الشريك** | جهة تدخل رابط الداعم بكلمة مرور. | `supporter_entity` |
| **رابط الداعم** (سابقاً رابط المتابعة) | رابط ثابت واحد بكلمة مرور لكل جهة. | `/supporter` |
| **المطلوب منك الآن** | بطاقات الإجراءات المحسوبة لكل شخص. | `GET /home` |
| **View as / الدخول كـ** | مبدّل أدوار للنموذج فقط. | لا يُنقل |
