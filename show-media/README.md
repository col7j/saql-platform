# وسائط عرض الحفل

ضع هنا ملفات الفيديو والصور، واكتب مسارها في شاشة التحكم (`#/show-admin`) أو في `public/show.json` هكذا: `show-media/intro.mp4`.

- **الفيديو:** MP4 بترميز H.264 وصوت AAC (يعمل في كل المتصفحات). 1080p بمعدل بت قرابة 6–8 ميغابت/ث يكفي للعرض.
- **الشرائح:** من PowerPoint: ملف ← تصدير ← PNG ← كل الشرائح، وضعها في `show-media/slides/` (Slide1.PNG, Slide2.PNG…)، ثم أضفها من شاشة التحكم بالنمط `show-media/slides/Slide{n}.PNG` والعدد.

## حدود GitHub Pages
- الملف الواحد: GitHub يرفض أكبر من **100 م.ب**، وينبّه فوق 50 م.ب. اجعل كل فيديو أقل من 50 م.ب.
- الموقع كله: حد **1 غ.ب**، وحدّ نقل شهري تقريبي 100 غ.ب.
- Git LFS **لا يُخدم** عبر GitHub Pages، فلا تستخدمه لهذه الملفات.
- الأكبر من ذلك: ارفعه من شاشة التحكم بزر «رفع من الجهاز» على جهاز العرض نفسه (يُحفظ في المتصفح عبر IndexedDB ولا يُنشر).
