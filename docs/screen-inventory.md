# جرد الشاشات والأزرار (الديمو الحالي)

لقطة من الكود والبيانات التجريبية على `feat/decisions-alignment` بعد `phase-4-fixes`. وُلّدت القوائم من `navFor` نفسها لكل حساب.

- **الحسابات:** القائد العام `leader`، مسؤول المالية `s5`، مسؤول التقنية والإعلامية `s6`، الميسّر `s1`، متابع الرحلات `s7`، قائد المجموعة `u1`، المشارك `u2`.
- **دوران بلا حساب مستقل في البيانات:**
  - مسؤول الإعلامية وحده: `s6` بعد إزالة عضويته في التقنية.
  - عضو فريق العمل بلا صفة: شخص إدارة مضاف للتجربة.
- **في البيانات التجريبية** `s1` عضو في اللجنة المالية ومعه صلاحيات عرض، فتظهر له المالية. هذا ليس جزءاً من دور الميسّر نفسه.

## 1. القائمة الجانبية والتنقل السفلي

**التنقل السفلي (الجوال):** الرئيسية، التقويم، أول عنصرين في قائمة الدور (عدا الأساسية)، ثم «القائمة» التي تفتح القائمة الجانبية كاملة.

**قسم «الأساسية» مشترك للجميع:** الرئيسية · التقويم · الإشعارات · ملفي. وفي الأعلى دائماً جرس الإشعارات.

| رفع مادة | المكتبة · تفاصيل اللقاء · الرحلة ← البيانات |
| طلب الميزانية مع الإنشاء ومن صفحة العنصر | الاجتماع · لقاء التركيز |

### نادرة الاستخدام أو زائدة

| الزر أو الإجراء | الملاحظة |
|---|---|
| إرجاع لمسودة (المجموعات) | للتجربة فقط، ويعيد البرنامج لما قبل التشكيل |
| سجّل نقاطاً يدوية | خارج القرار («لا مصادر نقاط أخرى»)، وموسوم «في أضيق الحدود» |
| أضف صورة عامة | يضيف صورة وهمية بلا رفع |
| النقاط المفتوحة (الإعدادات) | مفاتيح لنقاط حُسم أغلبها |
| خيار «مختلط» في طريقة البند | لا يغيّر الحساب |
| علّم كمشاهَدة (الرحلة ← البيانات) | يتكرر مع «شاهد» في المكتبة |
| تحليل التصنيفات (الجدول) | عرض لا يُبنى عليه إجراء |
| «رابط المتابعة» لكل فريق العمل | الإدارة فيه للقائد العام وحده، والبقية يرون رابطاً وتعليقات |
| «المؤشرات» لكل فريق العمل | عرض فقط |

### شاشات متشابهة

| الشاشات | وجه التشابه |
|---|---|
| طلباتي · المالية ← الطلبات · المالية ← العهد | الطلبات والعهد نفسها بزاويتين |
| المالية ← الفواتير · المالية ← العهد | البنود نفسها ونفس أزرار المراجعة |
| الأشخاص · المستخدمون | قائمة الأشخاص نفسها، والفرق أسماء الدخول وكلمات المرور |
| الخطط الشخصية · خطة مشارك · خطتي | العرض نفسه بصلاحيات مختلفة |
| المؤشرات · الرئيسية للقائد العام | متابعة المتأخر والمهام |
| رسائل المشاركين · راسل الإدارة | طرفا القناة نفسها |
| الموقع العام · رابط الداعم | قوالب العرض نفسها (الفريق، الأوائل، المجموعات) |

### شاشات فريق العمل: أين تتوزع

| ما يُدار | المكان | المالك |
|---|---|---|
| إضافة شخص | الأشخاص ← أضف شخصاً | القائد العام |
| الصلاحيات المؤقتة | الأشخاص ← بطاقة أسفل القائمة | القائد العام |
| البيانات العامة للفريق | ملف الشخص ← البيانات العامة | القائد العام |
| أسماء الدخول وكلمات المرور | المستخدمون | مسؤول التقنية |
| عضوية اللجان وقادتها | اللجان ← اللجنة ← الأعضاء | القائد العام وقائد اللجنة |
| صلاحيات أعضاء المالية | المالية ← الفريق والصلاحيات | مسؤول المالية |
| ميسّرو المجموعات وقادتها | المجموعات ← التشكيل | القائد العام |
| متابع الرحلات الدائم | الإعدادات ← متابع الرحلات | القائد العام |
| المتابع البديل لرحلة | الرحلة ← نظرة عامة | قائد الرحلة والقائد العام |
| قواعد تعارض الصفات | الإعدادات ← قواعد التعارض | القائد العام والتقنية |
| قوائم الأدوار ورئيسياتها | مخزّنة في `settings.ui` بلا شاشة | مسؤول التقنية |

**صعوبة الإيجاد:**
- **ستة أماكن مختلفة:** إدارة الشخص الواحد (إضافته، ودخوله، ولجانه، وصلاحياته، وصفته) تتوزع على الأشخاص، والمستخدمون، واللجان، والمالية، والمجموعات، والإعدادات، وليس بينها رابط مباشر.
- **القائد العام:**
  - لا يرى «المستخدمون».
  - «الصلاحيات المؤقتة» بطاقة في آخر صفحة الأشخاص، لا عنصر في القائمة.
  - «متابع الرحلات» تبويب داخل الإعدادات.
- **مسؤول التقنية:**
  - «المستخدمون» و«الإعدادات» في أعلى قائمته.
  - تبويبات الإعدادات المتاحة له: التقييم، والإشعارات، وقواعد التعارض، والتدقيق.
  - الصلاحيات المؤقتة وعضوية اللجان خارج أدواته.

### شاشة مراجعة الفواتير (المالية ← الفواتير)

**القائمة:** تظهر فقط النماذج التي فيها بند واحد على الأقل «محجوز للمراجعة». إن لم يوجد شيء تظهر رسالة فارغة: «لا بنود بانتظار المراجعة».

**بطاقة لكل نموذج صرف، من الأعلى للأسفل:**

| الجزء | ما يظهر | الأزرار |
|---|---|---|
| عنوان البطاقة | اسم النشاط (الرحلة أو اللقاء أو الاجتماع…) | — |
| تحت العنوان | صاحب العهدة · نوع الصرف | — |
| سطر النموذج | المورد · تاريخ الفاتورة · فاتورة أو إيصال تحويل · الرقم التسلسلي (أو شارة برتقالية «بلا رقم تسلسلي») | عرض المرفق (الصورة) على الطرف المقابل |
| التنبيهات | صناديق برتقالية: تكرار (البصمة، أو الرقم، أو المورد مع التاريخ والمبلغ)، وتجزئة (فواتير صغيرة متقاربة) | — |
| الرقم التسلسلي | حقل إدخال يدوي («مكان جاهز لقراءته آلياً لاحقاً») | احفظ (معطّل حتى يتغيّر الرقم) |
| بنود النموذج (سطر لكل بند) | التصنيف · البند (شرح حر) · المبلغ · شارة الحالة (محجوز، أو معتمد، أو مرفوض) · سطر «عدّلته المالية: كان…» إن عُدّل · ملاحظة المراجعة | — |
| تحت كل بند محجوز | قائمة التصنيف (وإن اقترح صاحب العهدة تصنيفاً جديداً: «اختر بديلاً لـ…») · حقل المبلغ | اعتمد · ارفض (نافذة سبب) |
| بند معتمد | — | طلب تعديل (يذهب للقائد العام) |

**ملاحظات على التخطيط:**
- **لا يظهر في البطاقة:** رصيد العهدة، ومجموع النموذج، وما صُرف قبله.
- **لا يوجد اعتماد جماعي** لبنود النموذج.
- **الأزرار تحت كل بند** لا على مستوى النموذج.
- **المراجع لا يرى أزرار المراجعة على عهدته الشخصية.**
- **البطاقة نفسها** تظهر أيضاً داخل بطاقة العهدة في «العهد والإغلاق».
