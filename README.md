# منصة صقل — النموذج الأولي

نموذج أولي تفاعلي لمنصة برنامج **صقل** لتنمية وتأهيل القيادات الشبابية في المدينة المنورة. واجهة عربية بالكامل (RTL)، ببيانات تجريبية محفوظة في المتصفح ودون خادم، ومعه مبدّل أدوار لتجربة المنصة بأي شخص.

## التجربة المباشرة
**https://col7j.github.io/saql-platform/**

كل زائر له نسخته الخاصة من البيانات التجريبية داخل متصفحه، فتعديلات أي مشرف لا تظهر لغيره.

## التشغيل محلياً
يتطلب Node.js 20 أو أحدث.
```
cd app
npm install
npm run dev
```
ثم افتح http://localhost:5173 وادخل باسم دخول وكلمة المرور `saql2026` (اسم الدخول أول البريد: `leader` للقائد العام، `s5` لمسؤول المالية، `s6` لمسؤول اللجنة التقنية، `s7` لمتابع الرحلات، `u1` لقائد مجموعة...)، أو استخدم شريط **«الدخول كـ»** في الأعلى للتنقل بين الأدوار.

## وضع «عرض الحفل»
شاشة عرض بملء الشاشة لحفل البرنامج، منفصلة عن بيانات المنصة ولا تكتب فيها.

- **شاشة التحكم:** `#/show-admin` (محلياً http://localhost:5173/#/show-admin): أضف الفقرات ورتّبها بالسحب، وعدّل الأسماء والإعدادات، وعاين كل فقرة، ثم «افتح شاشة العرض».
- **شاشة العرض:** `#/show` على الشاشة الخارجية. اضغط «ابدأ العرض» مرة واحدة (يسمح بالصوت ويفتح ملء الشاشة).
  - التالي: الكليكر أو → أو PageDown أو المسافة. السابق: ← أو PageUp.
  - `F` ملء الشاشة، `B` شاشة سوداء مؤقتة، باللمس: اسحب يميناً أو انقر يسار الشاشة للتالي.
  - المؤشر يختفي بعد ثانيتين، وشاشة التحكم تعمل ريموتاً (السابق/التالي/«اعرض الآن») على نفس الجهاز.
- **أنواع الفقرات:** فيديو (تشغيل تلقائي وزر تخطٍّ)، شرائح (صور مُصدّرة من PowerPoint)، ديمو المنصة (جولة متحركة في شاشات المنصة الحقيقية ببيانات ثابتة للقراءة فقط، والنقر بالفأرة على بطاقة يقرّبها)، أسماء (تظهر تباعاً)، وشاشة سوداء أو الشعار لفقرة المتحدث.
- **الإعدادات:** تُحفظ في المتصفح بمفتاح `show-config` (لا يتأثر بـ«إعادة البيانات» ولا برفع نسخة البيانات). عند غيابها تُقرأ `app/public/show.json`. ومن قائمة «الملف» في شاشة التحكم: تصدير واستيراد JSON واستعادة show.json.
- **الوسائط:** في `app/public/show-media` (تفاصيل الحدود في README داخله)، أو رفع محلي من شاشة التحكم يبقى على جهاز العرض فقط.
- إذا فشل ملف تظهر شاشة بديلة بالشعار وعنوان الفقرة ويكمل العرض.

**يوم الحفل:** افتح شاشة التحكم على جهاز العرض، وارفع الملفات المحلية إن وُجدت، ثم افتح شاشة العرض واسحبها للشاشة الخارجية واضغط F. جرّب العرض كاملاً مرة قبل الحفل على نفس الجهاز والمتصفح.

## الملفات
| الملف | المحتوى |
|---|---|
| `docs/saql-decisions.md` | وثيقة القرارات العامة المعتمدة (الأحدث، وتغلب عند التعارض) |
| `docs/saql-platform-spec.md` | وثيقة تصور المنصة (الأقدم) |
| `ASSUMPTIONS.md` | القرارات التي اتُّخذت حيث كانت الوثيقة صامتة، وتحتاج مراجعة المشرفين |
| `app/` | كود النموذج (React + TypeScript + Vite + Tailwind) |
| `app/public/show.json` | إعدادات عرض الحفل الافتراضية |
| `brand assets/` | الشعارات وخط ثمانية |

تفاصيل البنية التقنية في `app/README.md`.

## للمراجعين
- الملاحظات على السلوك أو الصلاحيات: راجعوا `ASSUMPTIONS.md` أولاً، فأغلب القرارات المفتوحة مسجلة فيه.
- كل الأوزان والمستهدفات والنقاط المفتوحة (القسم 20) قابلة للتعديل من شاشة **الإعدادات** بحساب القائد العام.
- زر **«إعادة البيانات»** في الشريط العلوي يعيد البيانات التجريبية لحالتها الأصلية.
